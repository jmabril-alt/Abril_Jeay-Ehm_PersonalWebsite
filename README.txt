MY MINIMALIST PERSONAL WEBSITE

Files:
- index.html: Home page
- about.html: About Me
- hobbies.html: Hobbies and Interests
- gallery.html: My Gallery
- favorites.html: My Favorites
- dreams.html: Dreams and Bucket List
- contact.html: Contact Me
- css/style.css: Shared styles for all pages
- images/: Put your own photographs here

HOW TO OPEN IN VISUAL STUDIO CODE
1. Extract this ZIP file.
2. Open Visual Studio Code.
3. Select File > Open Folder, then choose the extracted MinimalistPersonalWebsite folder.
4. Open index.html.
5. Right-click the page and choose "Open with Live Server" if you have the Live Server extension.
   You can also open index.html directly in your browser.

CUSTOMIZE
- Replace "Your Name", hometown, school, and sample descriptions with your own content.
- Replace sample online gallery images with photographs you have permission to use.
- To use a local image, put it inside images/ and use a path such as images/profile.jpg.
- Keep all seven HTML files and css/style.css in their current locations so navigation and styling work.

NOTE
The contact form is only a front-end demonstration. It does not send messages.
